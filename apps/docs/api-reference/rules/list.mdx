---
title: List Rules
description: Get all rules for a project.
---

```http
GET /rules/get-rules?apiKeyId={projectId}
```

**Headers:** `Authorization: Bearer <token>`

**Query Parameters:**

| Param | Required | Description |
|---|:---:|---|
| `apiKeyId` | ✅ | The project ID to scope rules to |

**Response (200):**
